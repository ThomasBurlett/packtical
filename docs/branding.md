# Packbee identity

Packbee is Mealbee's packing sibling: practical, warm, and quietly outdoorsy. The mark combines a honey-gold backpack, sage front pocket, and a small bee. Editable vector artwork and native PNG exports live in `app/assets/`; regenerate them with `node scripts/brand.mjs` from the app directory.

| Role | Color |
| --- | --- |
| Ink | `#24313A` |
| Warm cream | `#FFF4DE` |
| Paper | `#FFFDF8` |
| Honey gold | `#F4B942` |
| Sage | `#7E9B78` |
| Forest | `#385C48` |
| Clay | `#A8442E` |

Use generous touch targets, compact readable item rows, and clear checked/skipped states. Serif display headings contrast with practical sans-serif controls. The checklist is the focus; the landscape illustration belongs on the hub and welcome screen. Core assets are vector/native drawings, not remote imagery.

Tagline: **Pack well. Wander more.**
